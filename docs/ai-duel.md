# AI 대결

AI가 규칙대로 **모의 계좌**를 굴리고, 사용자는 실제로 매매해서 **같은 기준으로 성적을 비교**한다 (2026-11-23 사용자 요청).
AI 신호는 참고용이고, 선택과 주문은 사용자가 증권사 앱에서 한다. Atlas는 주문하지 않는다 (절대 규칙 1).

## 흐름 (`ai_daily`, 화~토 13:30·18:00, 시장 날씨·일봉 다음)

1. **체결**: 어제 낸 매수 신호(`planned`)를 신호 다음 거래일 **시가**에 모의 체결. 시가가 이미 손절가 아래면 사지 않는다
2. **청산**: 보유 포지션에 새 봉을 하나씩 적용 (`backend/src/ai/strategy.ts` `stepPosition`)
3. **계좌 가치**: 마지막 종가 기준 `ai_equity`
4. **스캔**: trader-scanner(④, 키 불필요) `daily` 모드로 미국 보통주 전체의 일봉 셋업을 찾는다. 거래대금 큰 30개만 1년 일봉을 받아 판단
5. **내 종목**: 내 보유 종목을 같은 매도 규칙으로 보고 매도 신호를 남긴다
6. **내 계좌 가치**: 총 투자금 + 실현 손익 + 평가 손익 → `my_equity`

## 규칙 "추세 추종 스윙 v1"

| 단계 | 규칙 |
| --- | --- |
| 시장 관문 | exposure-coach 판정이 **맑음**일 때만 새로 산다. 흐림·비면 같은 셋업도 **보류** |
| 셋업 | `breakout_20d`(20일 종가 신고가), `bull_flag`(깃발형)만 매수 후보. 20일선 회복·과매도는 관찰 |
| 종목 조건 | 종가 > 50일선, 50일선 > 200일선(이력 부족이면 건너뜀), 거래량 ≥ 50일 평균 × 1.2, RSI < 75 |
| 판정 | 종목 조건 모두 통과 + 맑음 → 매수, 종목 조건 통과 + 맑지 않음 → 보류, 그 외 → 관찰 |
| 진입 | 신호 다음 거래일 시가 |
| 손절가 | 신호 종가 − ATR(14) × 2 |
| 목표가 | 신호 종가 + 위험폭 × 2 (손익비 2) |
| 수량 | 손절되면 계좌의 1%를 잃는 수량. 종목당 계좌의 20%, 현금, 권장 비중 상한 안에서. 하루 3종목까지 |
| 매도 | 저가가 손절가에 닿으면 손절가(갭이면 시가), 고가가 목표가에 닿으면 목표가, 종가가 50일선 아래면 다음 날 시가, 20거래일 안에 +1R 못 넘으면 다음 날 시가. 같은 날 손절·목표 둘 다 닿으면 손절 먼저 |

규칙은 전부 스크립트 계산이다 (절대 규칙 2). Claude는 Phase 4에서 신호마다 쉬운 말 해설을 붙이는 데만 쓴다.

## 성적

| 항목 | AI | 나 |
| --- | --- | --- |
| 기준 | 시작 자금 (사용자가 고름) | 대결 시작일의 내 계좌 가치 |
| 수익률 | 계좌 가치 ÷ 시작 자금 | 내 계좌 가치 ÷ 기준 |
| 승률·거래 수 | 끝난 포지션 | "팔았음" 기록의 실현 손익 |
| 최대 낙폭 | `ai_equity` | `my_equity` |
| 비교 | S&P 500(SPY) 같은 기간 수익률 | |

내 성적은 총 투자금(`settings.capital`)이 있어야 잴 수 있다. 매매 기록("샀음/팔았음")을 남기면 보유 종목이 따라 바뀐다.

## 화면

- `/ai` AI 대결: 신호(발견한 셋업 → AI 판단 체크리스트 → 산다면 진입·손절·목표·수량 → 언제 파나), AI 보유·지난 거래, 성적표, 수익률 곡선(AI·나·S&P 500), 시작 자금 선택·새로 시작, 지금 실행
- `/records` 기록: 매매 기록 추가(샀음/팔았음), 목록, 실현 손익
- 홈: 오른쪽 "AI 신호" 카드, 오늘 할 일에 "AI 매도 신호"(내 종목)와 "AI가 다음 거래일 시가에 삽니다"
