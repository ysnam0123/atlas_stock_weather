# AI 대결

AI가 규칙대로 **모의 계좌**를 굴리고, 사용자는 실제로 매매해서 **같은 기준으로 성적을 비교**한다 (2026-11-23 사용자 요청).
규칙이 다른 AI 두 개(v1, v2)를 **같은 시작 자금으로 나란히** 돌린다. 같은 날 같은 스캔 결과를 각자 판단하므로 규칙만의 차이가 성적에 드러난다.
"최적의 규칙"은 과거에 숫자를 맞추지 않고, 이렇게 나란히 굴려서 고른다 (끝난 거래 30번 이상이 쌓여야 의미가 있다).
AI 신호는 참고용이고, 선택과 주문은 사용자가 증권사 앱에서 한다. Atlas는 주문하지 않는다 (절대 규칙 1).

## 흐름 (`ai_daily`, 화~토 13:30·18:00, 시장 날씨·일봉 다음)

1. **체결**: 매수 신호는 **조건부 매수 주문**(`planned`)이다. 신호 다음 거래일부터 3거래일 동안 고가가 조건 가격(신호 날 고가 + 1센트)을 넘은 첫날 체결한다. 시가가 이미 위면 시가, 장중에 넘으면 조건 가격. 3거래일 안에 못 넘으면 취소(`expired`). 2026-11-24 사용자 결정으로 다음 날 시가 체결에서 바꿈
2. **청산**: 보유 포지션에 새 봉을 하나씩 적용 (`backend/src/ai/strategy.ts` `stepPosition`)
3. **계좌 가치**: 마지막 종가 기준 `ai_equity`
4. **스캔**: trader-scanner(④, 키 불필요) `daily` 모드로 미국 보통주 전체의 일봉 셋업을 찾는다. 추세 셋업 먼저, 거래대금 큰 순으로 30개만 2년 일봉을 받아 판단. 그 30개와 관심 종목에 vcp-screener(③)를 돌려, 유효한 VCP가 돌파 직전·돌파 중이면 셋업 `vcp`를 더하고 조건부 매수가를 피벗 + 1센트로 쓴다
5. **내 종목**: 내 보유 종목을 같은 매도 규칙으로 보고 매도 신호를 남긴다
6. **내 계좌 가치**: 총 투자금 + 실현 손익 + 평가 손익 → `my_equity`

## 규칙 v1 "추세 추종 스윙"

| 단계 | 규칙 |
| --- | --- |
| 시장 관문 | exposure-coach 판정이 **맑음**일 때만 새로 산다. 흐림·비면 같은 셋업도 **보류** |
| 셋업 | `vcp`(유효한 VCP, 돌파 직전·중), `breakout_20d`(20일 종가 신고가), `bull_flag`(깃발형)만 매수 후보. 20일선 회복·과매도는 관찰. VCP 돌파 직전이면 거래량은 신호 날이 아니라 돌파하는 날 본다 |
| 종목 조건 | 종가 > 50일선, 50일선 > 200일선(이력 부족이면 건너뜀), 거래량 ≥ 50일 평균 × 1.2, RSI < 75 |
| 판정 | 종목 조건 모두 통과 + 맑음 → 매수, 종목 조건 통과 + 맑지 않음 → 보류, 그 외 → 관찰 |
| 진입 | 조건부 매수: 3거래일 안에 신호 날 고가 + 1센트를 넘으면 그 가격(갭이면 시가) |
| 손절가 | 신호 종가 − ATR(14) × 2 |
| 목표가 | 조건부 매수가 + 위험폭 × 2 (손익비 2) |
| 수량 | 조건부 매수가 기준으로 손절되면 계좌의 1%를 잃는 수량. 종목당 계좌의 20%, 현금(체결 안 된 주문 몫은 빼고), 권장 비중 상한 안에서. 하루 3종목까지. 이미 보유 중이거나 주문이 걸린 종목은 건너뜀 |
| 매도 | 저가가 손절가에 닿으면 손절가(갭이면 시가), 고가가 목표가에 닿으면 목표가, 종가가 50일선 아래면 다음 날 시가, 20거래일 안에 +1R 못 넘으면 다음 날 시가. 같은 날 손절·목표 둘 다 닿으면 손절 먼저 |

## 규칙 v2 "원칙 강화 스윙" (`backend/src/ai/strategy-v2.ts`)

미너비니 추세 템플릿과 오닐 CANSLIM 원칙을 더 충실히 따른다. v1에 더하거나 바꾼 것만 적는다.

| 단계 | v2 |
| --- | --- |
| 추세 | 종가 > 50일 > 150일 > 200일선, 200일선이 한 달 전보다 높음, 52주 저점보다 30% 이상 위, 52주 고점에서 25% 안 |
| 상대 강도 | 최근 6개월 수익률이 S&P 500(SPY)보다 높음 |
| 거래량 | 50일 평균의 1.5배 이상 |
| 실적 | 다음 실적 발표까지 7일 넘게 (모르면 막지 않음, 무료 플랜 한계) |
| 진입 | v1과 같은 조건부 매수. 시가가 조건 가격보다 3% 넘게 높게 시작하면 추격하지 않음 |
| 손절 | ATR×2(신호 종가 기준)와 조건부 매수가 −8% 중 가까운 쪽 (최대 손실 8%) |
| 이익 | 고정 목표 없음. +1R을 넘으면 손절가를 본전으로, 그 뒤 종가가 21일 지수이동평균 아래면 다음 날 시가에 정리 |
| +1R 전 | 종가가 50일선 아래면, 또는 15거래일 안에 +1R을 못 넘으면 다음 날 시가에 정리 |
| 수량 | 위험 1% (3번 연속 손절이면 0.5%), 종목당 20%, 최대 6종목, 하루 3종목 |
| 내 종목 매도 신호 | 손절가가 없으면 평단가 −8%를 손절가로 본다 |

섹터당 2종목 상한은 종목의 섹터 정보가 필요해 아직 없다 (FMP 유료 또는 다른 출처).

규칙은 전부 스크립트 계산이다 (절대 규칙 2). Claude는 신호마다 쉬운 말 해설을 붙이는 데만 쓴다.

포지션 관리는 봉 하나씩 차례로 적용한다. 계좌마다 마지막으로 처리한 날짜(`lastProcessedDate`) 다음 봉부터만 보므로 같은 봉을 두 번 적용하지 않는다.

## 내 계좌 기준 수량

매수·보류 신호와 홈 관심 카드에는 **내 총 투자금**에 v2 수량 규칙(위험 1%, 종목당 20%)을 적용한 수량도 보여준다. 증권사 앱에 같은 조건부 주문을 걸 수 있게 하려는 것이다. 현금은 총 투자금으로 본다.

## 성적

| 항목 | AI | 나 |
| --- | --- | --- |
| 기준 | 시작 자금 (사용자가 고름, v1·v2 같은 금액) | 대결 시작일의 내 계좌 가치 |
| 수익률 | 계좌 가치 ÷ 시작 자금 | 내 계좌 가치 ÷ 기준 |
| 승률·거래 수 | 끝난 포지션 | "팔았음" 기록의 실현 손익 |
| 최대 낙폭 | `ai_equity` | `my_equity` |
| 비교 | S&P 500(SPY) 같은 기간 수익률 | |

내 성적은 총 투자금(`settings.capital`)이 있어야 잴 수 있다. 매매 기록("샀음/팔았음")을 남기면 보유 종목이 따라 바뀐다.

## 화면

- `/ai` AI 대결: 규칙 버전 전환(v1·v2), 신호(매수·매도·관찰 탭, 판단 체크리스트, 진입·손절·목표·수량, 언제 파나, Claude 해설), 보유·지난 거래, 성적표(v1·v2·나), 수익률 곡선(v1·v2·나·S&P 500), 시작 자금 선택·둘 다 새로 시작, 지금 실행
- `/records` 기록: 매매 기록 추가(샀음/팔았음), 목록, 실현 손익
- 홈: 오른쪽 "AI 신호" 카드(v2 기준, 수익률은 v1·v2·나), 오늘 할 일에 "AI 매도 신호"(내 종목)와 "AI가 다음 거래일 시가에 삽니다"

## 바꿀 수 있는 것 (나중)

- VCP를 후보 30개가 아니라 S&P 500 전체에 돌리기 (야후 일봉 500종목, 3~4분)
- canslim-screener: 재무 데이터가 필요해 FMP 무료 플랜으로 되는지 확인
- 섹터 순위(상위 5위)를 종목 조건에 추가 (종목의 섹터 정보 필요, FMP)
- 규칙 버전을 신호에 기록해 버전별 성적 비교
