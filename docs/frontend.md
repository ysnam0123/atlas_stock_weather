# 프론트엔드

웹(Next.js) 반응형, 모바일 우선. 첫 목업: https://claude.ai/artifact/RDQjHgzf9QEJGqPe3svWFj (홈 · 아침 브리핑, 다크). 이후 색과 구성이 바뀌었으니 이 문서가 기준이다.

## 페이지

| 경로 | 페이지 | 역할 |
| --- | --- | --- |
| `/` | 홈 | 시간대별 브리핑 (아침·저녁·주말) |
| `/my` | 내 종목 | 보유·관심 목록, 보유 정보 입력, 손절가 선택 |
| `/records` | 기록 | 매매 기록 목록 (2차에 복기 기능이 들어갈 자리) |
| `/sectors` | 섹터 지도 | 11개 섹터 날씨 지도 (블록 1 완성 후) |
| `/search` | 검색 결과 | 티커·영문명·한글명·별칭 |
| `/stocks/[symbol]` | 종목 상세 | 깔때기 판정, 계획 오버레이 차트, 뉴스·실적, 결정 기록 |

경로는 영어로 둔다.

## 공통 레이아웃

- 상단: 왼쪽 `Atlas`, 오른쪽 원형 버튼 2개 — **+ 매매 기록 추가**, **돋보기 검색**
- 하단: 가운데 떠 있는 유리 재질 캡슐 탭바 — **홈 · 내 종목 · 기록 · 섹터 지도** (현재 탭은 배경 하이라이트)
- 홈 맨 아래: `다음 브리핑 오후 5시`, `오전 7시 4분 분석, 정규장 종가 기준`
- 상태 배지(분석 중, 일부 실패, 휴장 다음 날)는 맨 아래 기준 시각 줄에 표시

### 아침 모드 구성 (2026-11-23 2차 개편: 결론 먼저)

사용자: 개별주 몇 개를 들고 몇 주~몇 달 단위로 사고파는 스윙 투자 초보. 알고 싶은 것은 언제 살지·뭘 살지·언제 팔지·공부 전부.
홈은 **결론 → 확인할 것 → 근거(펼쳐서)** 순서다. 분석 재료(점수·차트)는 첫 화면에 늘어놓지 않는다.

| 순서 | 영역 | 내용 |
| --- | --- | --- |
| 1 | **결론 히어로** | 장 날짜("금요일 밤 미국 시장") → 날씨 단어 + 아이콘 → 결론 한 줄("새로 사지 말고 쉬는 날이에요") → 권장 주식 비중 한 줄 → "왜 그런가요?" (누르면 근거로 이동·펼침) |
| 2 | **오늘 확인할 것** | 할 일 목록. 시장(맑아지려면 남은 조건 n개), 내 종목(손절가까지 남은 거리, Phase 2 전엔 "보유 종목 등록" 안내), 일정(FMP 연결 전엔 안내) |
| 3 | **새로 살 후보** | 비·흐림이면 "찾지 않는 날" 한 줄. 맑음이면 조건을 모두 통과한 종목 (Phase 5) |
| 4 | **오늘의 한 줄 공부** | 그날 화면에 나온 용어 하나를 쉬운 말로. 장 날짜 기준으로 돌아가며 바뀐다 |
| 4-1 | **섹터** | 섹터 순위 1~5위 + "섹터 지도에서 11개 모두 보기", 그 아래 섹터 순위 흐름 히트맵(11 × 최근 20거래일). 데스크톱은 결론 오른쪽 |
| 5 | **시장 자세히 보기** (근거) | 시장 점수 수평선, 왜 이런 날씨인가(과거 대비 위치 + 6개 항목), 상승추세 비율 차트, 다시 맑아지려면(모바일만, 데스크톱은 오른쪽 카드). 모바일은 접혀 있고, 데스크톱은 펼쳐져 있다 |
| 6 | 기준 시각 | "다음 브리핑 …", "… 분석, M월 D일 정규장 종가 기준", 실행 상태 배지 |

- 용어(시장 점수, 상승추세, 판정 점수, 섹터 등)는 점선 밑줄을 긋고, 누르면 뜻이 뜬다. 뜻은 `features/learn/glossary.ts` 한 곳에서 관리한다
- 말투는 상태만 알린다. "사세요·파세요" 같은 지시, 예측 표현은 쓰지 않는다

### 반응형 (모바일 + 데스크톱 한 벌)

- 모바일(~1023px): 위 순서대로 한 줄, 상단 원형 버튼 2개 + 하단 유리 탭바. 근거는 "시장 자세히 보기"를 눌러야 펼쳐진다
- 데스크톱(1024px~): 왼쪽 사이드바(흰 바탕 위, 묶음 이름 "브리핑"·"내 투자", 현재 메뉴는 주황 글씨 + 왼쪽 막대) + 가운데 큰 흰 패널(왼쪽: 결론 → 확인할 것 → 후보 / 오른쪽: 섹터 순위 1~5위 → 섹터 순위 흐름 / 구분선 아래로 근거 펼침) + 오른쪽 카드 열(다시 맑아지려면, 내 종목, 오늘의 한 줄 공부; 화면 높이를 채우고 스크롤을 따라온다). 1280px 이상에서 패널 안이 두 칸
- 모바일은 흰 바탕 위에 섹션마다 테두리 카드. 데스크톱에서는 같은 섹션이 큰 패널 안에 카드 없이 들어간다 (모든 걸 같은 카드에 담지 않는다)

### 저녁 모드 (목업 미작성)

오늘 밤 새 매수 가능 여부 → 아침 이후 바뀐 것(18시 재실행 뉴스) → 오늘 밤 일정(KST) → 오늘의 후보 → 보유 종목 할 일

### 주말 모드 (목업 미작성)

금요일 밤 결과 → 보유 종목 주간 점검 → 섹터·테마 주간 흐름 → 다음 주 일정 → 관심 종목 주간 변화

## 종목 상세

위에서부터 "지금 어디쯤 → 계획 → 근거 → 내 결정".

1. 헤더: 한글명·영문명, 티커, 종가와 전일 대비, "정규장 종가 기준"
2. 깔때기 판정: 6단계를 쉬운 말로 (어디서 멈췄는지 한 줄)
3. 계획 차트: 일봉/주봉 캔들 + 오버레이 — 진입·손절·목표가 가로선, 지지·저항, 변동성 수축 구간(시작·끝 마커), 실적 발표일 마커, 내 매매 기록 마커, 20·50일 이동평균
4. 진입 계획: 조건 충족 n/m, 진입·손절·목표가, 손익비, 적정 수량
5. 뉴스·공시: KST, 제목 한국어 번역 + 원문 링크
6. 분기 실적: 6개 분기 (ETF는 숨김)
7. Claude 해석 + "깊게 분석"
8. 하단 고정: 샀음 · 팔았음 · 지켜봄

나중에 붙일 자리(차트 우측 상단): 장중 분봉(Yahoo), TradingView 공식 웹 위젯. 둘 다 "지금 가격"용이라 계획 차트와 탭으로 분리한다.

## 내 종목 편집 시트

입력: 수량, 평단가, 한글 별칭, 메모. 손절가는 세 방식(비율형·변동성형·차트형) 제안 중 선택하거나 직접 입력. 각 방식에 최대 손실 금액 표시. 수량 0이면 관심 종목으로 돌아간다. 증권사 계좌 연동은 하지 않는다.

## 검색

- 데이터: Nasdaq Trader 종목 목록 + SEC 티커·CIK + 한투 해외주식 마스터 한글명 + 사용자 별칭. ETF 포함(유형 배지)
- 정렬: 티커 앞글자 일치 → 이름 부분 일치 → 별칭
- 분석된 적 없는 종목: "아직 분석 안 됨, 관심에 추가하면 다음 실행부터 판정"

## 디자인 토큰 (대시보드 톤, 2026-11-23)

`frontend/src/app/globals.css`의 `@theme`에 등록돼 있다. 톤은 사용자가 보낸 대시보드 참고 이미지를 따른다: 흰 바탕 위에 흰 카드를 가는 테두리와 옅은 그림자로 구분하고, 주황은 현재 메뉴·주요 버튼·끝난 단계·선택된 탭에만 쓴다. Tailwind 클래스로 쓴다(`bg-primary`, `text-text-muted`). 기존 목업은 다크 팔레트이고 구성도 바뀌었다(위 "아침 모드 구성"). 색과 구성은 이 문서를 따른다.

| 토큰 | 값 | 용도 |
| --- | --- | --- |
| `primary` / `primary-hover` / `primary-tint` | `#F2603F` / `#E0502F` / `#FBE3DC` | 강조, 주요 버튼, 선택 상태 |
| `bg` | `#FFFFFF` | 페이지 바탕. 데스크톱 사이드바도 이 위에 그대로 놓인다 |
| `surface` | `#F6F6F6` | 보조 면: 고스트 버튼, 원형 버튼, 기간 전환 바탕, 회색 아이콘 원 |
| `surface-raised` | `#FFFFFF` | 흰 카드·패널, 시트 |
| `border` | `#EDEDED` | 구분선, 차트 격자 |
| `shadow-card` | 아주 옅은 2단 그림자 | 흰 카드를 `border`와 함께 살짝 띄운다 |
| `text` / `text-secondary` / `text-muted` | `#181818` / `#60605D` / `#9DA1A2` | 본문 / 보조 문장 / 메타 |
| `mist` / `steel` / `slate` | `#B2C5CA` / `#6E8C95` / `#697C84` | 차가운 보조색 (차트, 섹터 타일) |
| `sand` / `mocha` / `espresso` | `#D9C6AE` / `#887869` / `#534638` | 따뜻한 보조색 (차트, 섹터 타일) |

| `up` / `down` | `#D93A3A` / `#2563D9` | 등락 (한국식 상승 빨강, 하락 파랑). 상승은 `primary`보다 진하게 |
| `cond-clear` / `cond-cloudy` / `cond-rain` | `primary` / `slate` / `steel` 값 | 날씨 아이콘 |
| `sector-*` (11개) | `globals.css` 참고 | 섹터 아이콘 타일 (흰 아이콘이 올라가는 중간 톤) |

등락은 기호(▲▼)를 같이 써서 색만으로 구분하지 않는다. 미정: 경고 `warn` (할 일 캡슐 만들 때).

- 글꼴: `-apple-system, system-ui, 'Apple SD Gothic Neo', 'Pretendard', sans-serif`. SF 폰트 파일은 웹에 넣지 않는다
- 크기: 히어로 56px / 300 / -0.035em, 섹션 제목 20px / 600, 목록 17px, 보조 13px. 숫자는 `tabular-nums`
- 모서리: 그룹·카드 20px, 아이콘 타일 10px, 원형 버튼 44px, 탭바 캡슐 32px
- 유리 재질(탭바만): 반투명 배경 + `backdrop-filter: blur(22px) saturate(170%)`, `prefers-reduced-transparency`에서 불투명
- 모션: 시트·탭 전환은 감쇠 1.0 스프링(겹침 없음), 버튼은 누르는 순간 반응. `prefers-reduced-motion`에서 페이드로 대체
- 터치 영역 44px 이상, 대비 4.5:1 이상
