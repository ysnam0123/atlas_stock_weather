# 프론트엔드

웹(Next.js) 반응형, 모바일 우선. 기준 목업: https://claude.ai/artifact/RDQjHgzf9QEJGqPe3svWFj (홈 · 아침 브리핑, 다크). 목업의 숫자와 종목은 모두 예시다.

## 페이지

| 경로 | 페이지 | 역할 |
| --- | --- | --- |
| `/` | 홈 | 시간대별 브리핑 (아침·저녁·주말) |
| `/my` | 내 종목 | 보유·관심 목록, 보유 정보 입력, 손절가 선택 |
| `/records` | 기록 | 매매 기록 목록 (2차에 복기 기능이 들어갈 자리) |
| `/sectors` | 섹터 지도 | 11개 섹터 날씨 지도 (블록 1 완성 후) |
| `/search` | 검색 결과 | 티커·영문명·한글명·별칭 |
| `/stocks/[symbol]` | 종목 상세 | 깔때기 판정, 계획 오버레이 차트, 뉴스·실적, 결정 기록 |

경로는 영어로 둔다.

## 공통 레이아웃

- 상단: 왼쪽 `Atlas`, 오른쪽 원형 버튼 2개 — **+ 매매 기록 추가**, **돋보기 검색**
- 하단: 가운데 떠 있는 유리 재질 캡슐 탭바 — **홈 · 내 종목 · 기록 · 섹터 지도** (현재 탭은 배경 하이라이트)
- 홈 맨 아래: `다음 브리핑 오후 5시`, `오전 7시 4분 분석, 정규장 종가 기준`
- 상태 배지(분석 중, 일부 실패, 휴장 다음 날)는 맨 아래 기준 시각 줄에 표시

## 홈 모드 (탭 없음, 한국 시간으로 자동 결정)

| 요일·시간 | 모드 |
| --- | --- |
| 화~금 분석 완료(07시경) ~ 17시 | 아침: 밤사이 결과 |
| 월~금 17시 ~ 다음 날 06시 | 저녁: 오늘 밤 준비 (23:30 이후 "장 진행 중") |
| 토 07시 ~ 월 17시 | 주말: 한 주 점검 (월요일 아침엔 새 장 결과가 없으므로 유지) |
| 06시 ~ 분석 완료 | 직전 모드 유지 + "오늘 분석 대기" |

17시는 기본값, 설정에서 변경.

### 아침 모드 구성 (목업 기준, 위에서부터)

1. **날씨 히어로**: 작은 글씨 "밤사이 미국 시장" → 큰 얇은 글씨 "맑음" + 날씨 아이콘 → 한 문장 "투자금의 70%까지 주식에 둬도 괜찮은 날이에요." (권장 주식 비중) → 화면 폭 전체 가는 수평선(점 = 오늘 시장 점수, 작은 눈금 = 어제) → "시장 점수 68, 어제 64" + "점수 읽는 법" 링크
2. **할 일 캡슐** (있을 때만): 손절가 도달 등. 주간거래(증권사별 대략 10~18시) 주의 문구
3. **내 종목**: 세로 그룹 목록. 이름, 변화 사유(새 공시, 손절가 도달, 실적 발표), 전일 대비 등락
4. **관심 종목**: 가로 스크롤 카드(스냅). 카드 안에 최근 가격 미니 차트 + 진입가 점선, 상태 문장("진입 계획이 나왔어요" / "실적 조건에서 멈췄어요") + 점 6개 진행 표시(걸린 단계는 주황 테두리)
5. **섹터 순위**: 1~5위. 색 아이콘 타일 + 섹터명 + 상승추세 비율 + 어제 대비. 마지막 줄 "섹터 지도에서 11개 모두 보기"
6. 기준 시각과 다음 브리핑

보유 종목이 없는 사용자는 3번 대신 "종목 추가" 안내를 둔다.

### 저녁 모드 (목업 미작성)

오늘 밤 새 매수 가능 여부 → 아침 이후 바뀐 것(18시 재실행 뉴스) → 오늘 밤 일정(KST) → 오늘의 후보 → 보유 종목 할 일

### 주말 모드 (목업 미작성)

금요일 밤 결과 → 보유 종목 주간 점검 → 섹터·테마 주간 흐름 → 다음 주 일정 → 관심 종목 주간 변화

## 종목 상세

위에서부터 "지금 어디쯤 → 계획 → 근거 → 내 결정".

1. 헤더: 한글명·영문명, 티커, 종가와 전일 대비, "정규장 종가 기준"
2. 깔때기 판정: 6단계를 쉬운 말로 (어디서 멈췄는지 한 줄)
3. 계획 차트: 일봉/주봉 캔들 + 오버레이 — 진입·손절·목표가 가로선, 지지·저항, 변동성 수축 구간(시작·끝 마커), 실적 발표일 마커, 내 매매 기록 마커, 20·50일 이동평균
4. 진입 계획: 조건 충족 n/m, 진입·손절·목표가, 손익비, 적정 수량
5. 뉴스·공시: KST, 제목 한국어 번역 + 원문 링크
6. 분기 실적: 6개 분기 (ETF는 숨김)
7. Claude 해석 + "깊게 분석"
8. 하단 고정: 샀음 · 팔았음 · 지켜봄

나중에 붙일 자리(차트 우측 상단): 장중 분봉(Yahoo), TradingView 공식 웹 위젯. 둘 다 "지금 가격"용이라 계획 차트와 탭으로 분리한다.

## 내 종목 편집 시트

입력: 수량, 평단가, 한글 별칭, 메모. 손절가는 세 방식(비율형·변동성형·차트형) 제안 중 선택하거나 직접 입력. 각 방식에 최대 손실 금액 표시. 수량 0이면 관심 종목으로 돌아간다. 증권사 계좌 연동은 하지 않는다.

## 검색

- 데이터: Nasdaq Trader 종목 목록 + SEC 티커·CIK + 한투 해외주식 마스터 한글명 + 사용자 별칭. ETF 포함(유형 배지)
- 정렬: 티커 앞글자 일치 → 이름 부분 일치 → 별칭
- 분석된 적 없는 종목: "아직 분석 안 됨, 관심에 추가하면 다음 실행부터 판정"

## 한국어 처리

| 영역 | 처리 |
| --- | --- |
| 종목명 | 한투 마스터 한글명 + 별칭 |
| 뉴스 제목 | 실행마다 새 제목만 모아 Claude로 한 번에 번역 |
| 스킬 리포트 | Claude 종합 단계에서 한국어 문장 (`summaryKo`, `reasonKo`) |
| 시간 | 전부 KST |
| 용어 | MVP는 원래 용어. 쉬운 말·툴팁은 MVP 이후 |
| 금액 | 달러. 원화 환산은 2차 |

| 토큰 | 값 | 용도 |
| --- | --- | --- |

| `text-2` | `#c9d1d9` | 보조 문장 |

| `up` / `down` | `#3fb950` / `#f85149` | 등락 (기호 ▲▼ 또는 +/−를 같이 써서 색만으로 구분하지 않음) |
| `warn` | `#d29922` | 손절가 도달, 걸린 단계 |
| `link` | `#58a6ff` | 링크 |
| `cond-clear` / `cond-cloudy` / `cond-rain` | `#e3b341` / `#b1bac4` / `#79c0ff` | 날씨 아이콘, 수평선 점 |
| 섹터 타일 | 기술 `#2f6fbf`, 산업재 `#6e7681`, 금융 `#238a63`, 커뮤니케이션 `#7a4fd0`, 헬스케어 `#c2414f` | 나머지 6개는 같은 채도로 추가 |

- 글꼴: `-apple-system, system-ui, 'Apple SD Gothic Neo', 'Pretendard', sans-serif`. SF 폰트 파일은 웹에 넣지 않는다
- 크기: 히어로 56px / 300 / -0.035em, 섹션 제목 20px / 600, 목록 17px, 보조 13px. 숫자는 `tabular-nums`
- 모서리: 그룹·카드 20px, 아이콘 타일 10px, 원형 버튼 44px, 탭바 캡슐 32px
- 유리 재질(탭바만): 반투명 배경 + `backdrop-filter: blur(22px) saturate(170%)`, `prefers-reduced-transparency`에서 불투명
- 모션: 시트·탭 전환은 감쇠 1.0 스프링(겹침 없음), 버튼은 누르는 순간 반응. `prefers-reduced-motion`에서 페이드로 대체
- 터치 영역 44px 이상, 대비 4.5:1 이상

## 상태 처리

| 상황 | 표시 |
| --- | --- |
| DB 비어 있음 | 시작 안내: 관심 종목 추가 → 첫 분석 실행 |
| 분석 대기·진행 중 | 이전 데이터 유지 + 배지 |
| 특정 스킬 실패 | 해당 영역만 "데이터 없음", 나머지 정상 |
| 날씨 흐림·비 | 후보 영역 접힘 + 이유 한 줄 |
| 후보 0개 | "오늘 모든 조건을 통과한 종목 없음" (정상 결과) |
| 휴장 다음 날 | "어젯밤 미국장 휴장, 새 결과 없음" |
