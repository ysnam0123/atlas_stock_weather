### 홈 구성 (2026-11-23 3차 개편: 트레이더 홈)

기준: "전업 스윙 트레이더가 이 화면 하나만 본다면". 트레이더가 아침에 묻는 순서대로 놓는다.
공부 카드와 큰 결론 글씨는 뺐다. 용어 뜻은 점선 밑줄(`Term`)로 남는다.

| 순서 | 영역 | 내용 | 데이터 |
| --- | --- | --- | --- |
| 1 | **시장 자세** 띠 | 날씨 + 결론 한 줄, 권장 비중 상한, **내 주식 비중**(보유 평가금 ÷ 총 투자금, 상한 초과 표시), 오늘의 자세(새 매수 쉼 / 조건 맞으면 매수), 오르는 종목(상승추세 비율, 전 거래일 대비) | exposure-coach, `settings.capital` |
| 2 | **오늘 할 일** (급한 순) | 손절가 아래 마감 → 손절가 근접 → 비중 초과 → 목표가 도달 → 손절가 없음 → 보유 등록·총 투자금 → 맑아지려면 조건 → 관심은 지켜보기만 → 일정(FMP 전 안내) | 규칙 (Claude 안 씀) |

| 3-1 | **AI 신호** (오른쪽 칸) | 최근 장의 AI 신호(매도·매수·보류·관찰) 요약, AI vs 나 수익률, AI 대결로 이동. 오늘 할 일에 내 종목 AI 매도 신호·AI 매수 예정 | `ai_signals` |
| 4 | **관심 → 매수 대기** | 종가·등락, 날씨에 따른 상태(맑아지면 확인). Phase 5에서 진입가·손절가·수량 | `watchlist` |
| 5 | **이번 주** | 경제지표·실적 발표 (KST). FMP 전 안내 | FMP (나중) |
| 6 | **섹터 순위** | 1~5위 + 섹터 지도 링크 | sector-analyst |
| 7 | **흐름과 근거** | 흐름(상승추세 비율 차트 + 섹터 순위 히트맵), 근거(왜 이런 날씨인가 + 시장 점수 수평선, 다시 맑아지려면). 모바일 접힘, 데스크톱 펼침 | |
| 8 | 기준 시각 | 다음 브리핑, 분석 시각, 정규장 종가 기준 | |

### 반응형 (모바일 + 데스크톱 한 벌)

- 모바일(~1023px): 위 표 순서대로 카드가 한 줄, 상단 원형 버튼 2개 + 하단 유리 탭바. 흐름과 근거는 눌러야 펼쳐진다
- 데스크톱(1024px~): 왼쪽 사이드바(흰 바탕 위, 묶음 이름 "브리핑"·"내 투자", 현재 메뉴는 주황 글씨 + 왼쪽 막대) + 가운데 큰 흰 패널(시장 자세 띠 / 오늘 할 일 | 섹터 순위 / 보유 종목 표 / 흐름과 근거) + 오른쪽 카드 열(관심 → 매수 대기, 이번 주; 화면 높이를 채우고 스크롤을 따라온다). 1280px 이상에서 패널 안이 두 칸, 보유 종목은 표
- 모바일은 흰 바탕 위에 섹션마다 테두리 카드. 데스크톱에서는 같은 섹션이 큰 패널 안에 카드 없이 들어간다 (모든 걸 같은 카드에 담지 않는다)

### 종목 상세 (`/stocks/[symbol]`, 2026-11-24)

검색 결과, 홈 보유 종목 행, 관심 카드, AI 신호에서 들어온다. 맨 위 종목·종가·버튼(뉴스·실적·의원 거래 시트, 관심, 보유 등록·편집) → 차트(3개월~2년, 일봉 정규장 종가, 거래량, 50·200일선, 계획 가격선: 내 평단·손절가·목표가는 실선, 조건부 매수가·규칙 손절가·VCP 피벗은 점선, 오른쪽 축에 이름표) → "지금 사도 되는 자리인가"(AI v2 규칙 체크리스트, VCP, 내 계좌 수량) | 내 포지션·매매 기록, AI는 이 종목을.

### 섹터 지도 (`/sectors`, 2026-11-24)

11개 섹터를 상승추세 비율로 줄 세운다. 국면 네 칸(주도·식는 중·살아나는 중·소외)은 비율의 높낮이(11개 가운데값)와 1개월 방향으로 나눈다.
전체 순위 표: 상승추세 비율, 1주·1개월 변화(%p), 한 달 전 대비 순위 이동, 대표 섹터 ETF(SPDR) 1개월 수익률, S&P 500 대비 3개월. 행을 누르면 1년 흐름 차트(1년 가운데값 점선).

## 종목 상세

위에서부터 "지금 어디쯤 → 계획 → 근거 → 내 결정".

1. 헤더: 한글명·영문명, 티커, 종가와 전일 대비, "정규장 종가 기준"
2. 깔때기 판정: 6단계를 쉬운 말로 (어디서 멈췄는지 한 줄)
3. 계획 차트: 일봉/주봉 캔들 + 오버레이 — 진입·손절·목표가 가로선, 지지·저항, 변동성 수축 구간(시작·끝 마커), 실적 발표일 마커, 내 매매 기록 마커, 20·50일 이동평균
4. 진입 계획: 조건 충족 n/m, 진입·손절·목표가, 손익비, 적정 수량
5. 뉴스·공시: KST, 제목 한국어 번역 + 원문 링크
6. 분기 실적: 6개 분기 (ETF는 숨김)
7. Claude 해석 + "깊게 분석"
8. 하단 고정: 샀음 · 팔았음 · 지켜봄

나중에 붙일 자리(차트 우측 상단): 장중 분봉(Yahoo), TradingView 공식 웹 위젯. 둘 다 "지금 가격"용이라 계획 차트와 탭으로 분리한다.

## 디자인 토큰 (대시보드 톤, 2026-11-23)

`frontend/src/app/globals.css`의 `@theme`에 등록돼 있다. 톤은 사용자가 보낸 대시보드 참고 이미지를 따른다: 흰 바탕 위에 흰 카드를 가는 테두리와 옅은 그림자로 구분하고, 주황은 현재 메뉴·주요 버튼·끝난 단계·선택된 탭에만 쓴다. Tailwind 클래스로 쓴다(`bg-primary`, `text-text-muted`). 기존 목업은 다크 팔레트이고 구성도 바뀌었다(위 "아침 모드 구성"). 색과 구성은 이 문서를 따른다.

| 토큰 | 값 | 용도 |
| --- | --- | --- |
| `primary` / `primary-hover` / `primary-tint` | `#F2603F` / `#E0502F` / `#FBE3DC` | 강조, 주요 버튼, 선택 상태 |
| `bg` | `#FFFFFF` | 페이지 바탕. 데스크톱 사이드바도 이 위에 그대로 놓인다 |
| `surface` | `#F6F6F6` | 보조 면: 고스트 버튼, 원형 버튼, 기간 전환 바탕, 회색 아이콘 원 |
| `surface-raised` | `#FFFFFF` | 흰 카드·패널, 시트 |
| `border` | `#EDEDED` | 구분선, 차트 격자 |
